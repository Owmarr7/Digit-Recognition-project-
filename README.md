# Handwritten Digit Recognition

A beginner machine learning project that recognizes handwritten digits
from 0 to 9 using PyTorch.

## Goals

- Explore the MNIST dataset
- Understand image preprocessing
- Build and train a neural network
- Evaluate model accuracy
- Experiment with GPU acceleration

## Technologies

- Python
- PyTorch
- NumPy
- Matplotlib
- Scikit-learn

## Test

Used streamlit to test the ML model my hand drawings
